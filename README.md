# ⚔️ Shafin Blade Fighter 3D // শাফিন ব্লেড ফাইটার

**Shafin Blade Fighter 3D** is a fast-paced, high-octane 2D/3D cyber anime action fighting game developed with pure HTML5 Canvas and modern JavaScript. Engineered with responsive dual-analog/touch gamepad controls, dynamic visual effects, combo hit-counters, and complete Progressive Web App (PWA) offline support.

---

## 🎮 Character Roster (যোদ্ধাদের তালিকা)

* 🗡️ **Shafin (The Blade Master):** High agility, lightning katana slices, and explosive combo finish.
* ⚡ **Nafis (Thunder Fist):** Heavy strikes, shockwave counter-attacks.
* 🔥 **Tamim (Blaze Striker):** Rapid kicks and fiery projectile bursts.
* 🛡️ **Hamza (Iron Guard):** High defense, armored dashes, and crushing throws.
* 🌪️ **Aavon (Shadow Rogue):** Teleportation steps and multi-hit critical stabs.

---

## 🕹️ Controls (খেলার নিয়ম ও বাটন)

### 💻 Desktop / Keyboard Controls
| Action | Key 1 | Key 2 |
|---|---|---|
| **Move Left** | `A` | `Left Arrow` |
| **Move Right** | `D` | `Right Arrow` |
| **Jump** | `W` | `Up Arrow` / `Space` |
| **Crouch / Block** | `S` | `Down Arrow` |
| **Light Slash** | `J` | `Z` |
| **Heavy Strike** | `K` | `X` |
| **Special Super Attack** | `L` | `C` |

### 📱 Mobile / Touch Controls
* Dynamic on-screen virtual joystick for movement.
* Action touch-pads with visual feedback for Attack, Jump, and Super Combos.

---

## 🚀 Features

* ⚡ **Instant Loading:** Zero external heavy engine overhead; powered by native Web Canvas rendering at 60 FPS.
* 📱 **PWA Offline Support:** Installable as a standalone app on Android and iOS devices; playable without internet.
* 🎶 **Dynamic Audio Engine:** Procedural synthesizers and retro combat sound effects via the Web Audio API.
* 🌆 **Cyber City Arenas:** Animated background parallax with particle sparks and impact effects.

---

## ⚡ Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/monisharani333022-eng/Shafin-Blade-Fighter-Game.git
   cd Shafin-Blade-Fighter-Game
   ```

2. **Open in Browser:**
   Simply open `index.html` in Chrome, Brave, or Edge!

3. **Or run with local Node.js server:**
   ```bash
   npm start
   ```
